# Sorry, I Heard That Wrong

[![make.fun · u-kiencx-sorry-i-heard-that-wrong-1858c729](https://make.fun/badge/u-kiencx-sorry-i-heard-that-wrong-1858c729.svg)](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729)

The apology a smart speaker gives after mishearing its owner — one line, 123 characters:

> Sorry — I heard 'dim the lights' as 'dine the lights,' so I have eaten all six bulbs and enrolled myself in a hearing test.

"Dim" → "dine" is a fresh mishearing (not a song title, not a name). The twist
escalates in one beat — the speaker literally ate the bulbs — and the closer
is the device diagnosing its own ears: a smart speaker enrolling itself in a
hearing test.

## Run it

```sh
node main.ts
```

The program writes exactly one line to `/output/entry.txt` (override with
`OUTPUT_PATH` for local testing). No trailing newline.
